# Verkehrsinstitut Starick-Anleitung: 
Windows-PC mit dem Smartboard verbinden


Mit dieser Anleitung kannst du den Bildschirm deines Windows-PCs kabellos auf das Smartboard übertragen.
So kannst du beispielsweise Präsentationen, Bilder oder andere Inhalte direkt auf dem Smartboard anzeigen.


# Schritt 1: Smartboard einschalten
  Schalte das Smartboard ein und tippe auf Bildschirmfreigabe.

# Schritt 2: Verbindung vorbereiten
  Stelle sicher, dass dein Windows-PC mit dem Gäste Wlan verbunden ist.

# Schritt 3: Verbindung am Windows-PC öffnen
  Drücke auf deiner Tastatur gleichzeitig die Tasten „Windows + K“.
  Es öffnet sich ein Fenster mit verfügbaren drahtlosen Bildschirmen.

# Schritt 4: Smartboard auswählen
  Wähle in der Liste das angezeigte Smartboard aus.

# Schritt 5: Verbindung bestätigen
  Warte, bis die Verbindung hergestellt wurde.

# Schritt 6: Bildschirmübertragung einstellen
  Wenn die Verbindung hergestellt ist, kannst du mit „Windows + P“ auswählen, wie dein Bildschirm angezeigt werden soll:

   - Duplizieren: Auf dem PC und dem Smartboard wird derselbe Inhalt angezeigt.
   - Erweitern: Das Smartboard wird als zusätzlicher Bildschirm verwendet.
   - Nur zweiter Bildschirm: Die Anzeige erfolgt ausschließlich auf dem Smartboard.
   - Nur erster Bildschirm: Die Anzeige erfolgt ausschließlich auf dem Windows PC

  Für Präsentationen ist normalerweise die Einstellung „Duplizieren“ am besten geeignet.

# Schritt 7: Verbindung beenden
  Wenn du die Übertragung beenden möchtest, drücke erneut „Windows + K“, wähle das verbundene Smartboard aus und trenne    die Verbindung.
